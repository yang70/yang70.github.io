# Sandy OpenClaw — Google integration information

Static information pages for a personal, read-only Gmail, Drive, Docs and Sheets integration.

Planned GitHub Pages address: https://yang70.github.io/

- `index.html`: purpose, capabilities, scope and contact.
- `privacy.html`: access, AI processing, storage, retention, revocation and website hosting.
- `terms.html`: personal use and assistant limitations.
- `styles.css`: local responsive styling; no external assets or scripts.
- `.nojekyll`: publish the static files directly.

This repository contains informational website content only. It must never contain OAuth credentials, assistant configuration, private messages, Google documents, tokens or transcripts.

The website does not provide Google sign-in, public assistant registration, API access or a connection to the private assistant computer. Publishing these files does not grant access to that computer or its Google account.

Search Console ownership verification may require adding the owner's public verification meta tag or HTML verification file. Google OAuth publishing/verification is a separate process and is not guaranteed by hosting this site.
