Sandy OpenClaw helps its owner understand email, documents and spreadsheets through a private assistant conversation.

Read-only Google access

What the integration does

Gmail
Search messages and read relevant emails to answer questions or prepare summaries.
Google Docs
Find accessible files in Google Drive and read document text to provide context for a conversation.
Google Sheets
Read spreadsheet information and bounded cell ranges to explain figures, compare entries and answer questions.

The owner can also request scheduled read-only checks and choose when and where summaries are delivered.

Access stays under the owner's control

The owner signs in directly with Google and approves read-only access. Google permissions cover the authorized account's readable mailbox and accessible Drive files, including Docs and Sheets. The assistant fetches information relevant to the owner's request or chosen routine.

This integration cannot send email, change mailbox labels, or edit or delete Google files. Retrieved content can be processed by configured AI services and retained in assistant history; the privacy policy explains this handling.

This website is an information page for a personal deployment. It has no sign-up, Google sign-in or connection to the assistant's private control interface.

Questions and access requests

The deployment is maintained by GitHub user yang70. For general questions, use the site's GitHub issue tracker. Do not include account credentials, private email or document content in a public issue.
