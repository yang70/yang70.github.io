Google integration

Privacy policy

Effective October 9, 2026

This policy describes the personal Sandy OpenClaw deployment maintained by GitHub user yang70. It applies to the Google integration and this informational website.

Data accessed

After the owner authorizes Google OAuth access, the integration can read Gmail message content and metadata; Google Drive file listings and metadata; Google Docs text and document information; and Google Sheets spreadsheet information and requested cell ranges. It also uses the authorized account's email identity to select the account.

Read authorization covers readable mailbox data and Drive files accessible to that account, rather than a single file or folder. Helpers limit individual searches, request sizes and excerpts. Optional Sheets editing requires separate owner consent to Google's account-wide spreadsheet editing scope. The local write helper fixes the target to owner-approved spreadsheets; that file restriction is enforced locally, not by Google's broad editing scope.

Purpose and limits

Google data is used to answer the owner's questions, summarize relevant information and perform routines specifically requested by the owner. After additional editing consent, the assistant can update or append spreadsheet cells and perform formatting or tab changes in approved spreadsheets. Destructive and structural commands require owner command approval. The integration has no permission to send email, create drafts, change labels or read status, edit Google Docs, or delete Drive files.

The deployment operator does not sell Google data, publish it on this site, or use it for advertising or credit decisions. Google data and derived content are subject to the Google API Services User Data Policy, including its Limited Use requirements.

AI processing and message delivery

Relevant Google content can be included in requests to the assistant's configured AI providers. At the effective date, OpenAI processes assistant requests and Google Gemini processes conversation summaries. Data handling by these providers depends on their service terms and the owner's account settings; this deployment does not guarantee that provider processing has zero retention or excludes service improvement. The configured free-tier Gemini service may use submitted content to improve Google's products.

Replies or routine summaries can be sent through Telegram when the owner chooses that channel. Telegram then handles that message content under its own terms. Google data is not sent to GitHub Pages as part of operating the integration.

Storage and security

OAuth client secrets and refresh tokens are stored in an encrypted file keyring on the owner's private assistant computer, with access restricted to its operating-system account. The keyring's unlock secret is stored separately in a restricted local file. This protects file access but does not prevent a person with full access to that operating-system account from using the credentials.

Retrieved excerpts, generated answers and summaries may persist in local assistant conversation history, context-management storage or backups, and in Telegram chats when sent there. Conversation storage is not described as encrypted by this policy. The deployment does not currently enforce an automatic deletion period for all such records.

Revocation and deletion

The owner can revoke future Google access through Google Account connections. Revoking access does not erase previously stored assistant history, summaries, backups or Telegram messages. Removing those copies requires deleting them from the relevant local storage, backups and message service. Questions about access or deletion should be raised privately with the deployment owner; do not post private content in the public issue tracker.

Website visitors

This static website has no application analytics, tracking scripts, forms, Google sign-in or application cookies. It is hosted by GitHub Pages, which may collect standard service and security information about visits under GitHub's privacy statement. Following an external link subjects that visit to the destination's policies.

Changes and contact

This page will be updated if the integration's access or data handling changes. Expanded Google permissions require a new authorization review. General questions can be submitted through the GitHub issue tracker; sensitive requests should use a private channel with the owner.
